Codex Calculator

A modern calculator web application built entirely with AI-assisted development using Codex and powered by Next.js.

Overview

Codex Calculator is a lightweight, responsive calculator application designed to demonstrate AI-generated software development workflows. The project was created from scratch through iterative prompts and code generation using Codex.

Features
Basic arithmetic operations
Addition
Subtraction
Multiplication
Division
Responsive user interface
Fast performance with Next.js
Modern React-based architecture
Clean and minimal design

Next.js
React
TypeScript
Lucide React Icons
Getting Started
Prerequisites
Node.js 20+
npm
Installation

Clone the repository:

git clone https://github.com/OliverYao09/codex-calculator.git
cd codex-calculator

Install dependencies:

npm install

Run the development server:

npm run dev

Open your browser and visit:

http://localhost:3000
Build for Production
npm run build
npm start
Deployment

This project can be deployed easily using Vercel.

npm run build

Or connect the GitHub repository directly to Vercel for automatic deployments.
